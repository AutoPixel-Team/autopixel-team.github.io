Pocket Life 개인정보처리방침

앱: Pocket Life · 운영자: 윤소프트(YoonSoft) · Google Play 개발자 표시명: YoonSoft Studio · 시행일: 2026년 11월 26일

Pocket Life(이하 "앱")는 윤소프트(YoonSoft)가 운영하고, Google Play에는 개발자 이름 "YoonSoft Studio"로 표시돼요. 앱은 게임에 꼭 필요한 정보만 처리해요. 이 방침은 앱이 어떤 정보를, 왜, 얼마나 오래 처리하는지 설명해요.

1. 처리하는 정보

정보언제목적
무작위 계정 번호(이메일 없이 시작하는 로그인)앱을 처음 열 때 자동코인·상품·보상을 서버에서 안전하게 관리
로그인 세션 정보(IP 주소, 접속한 앱 정보)로그인할 때 자동로그인 유지, 부정 접속 방지
Google 계정 이메일, 이름, 프로필 사진 주소, Google 고유 ID사용자가 "Google 계정 연결"을 선택한 경우만기기 변경·재설치 때 진행 복원, 본인 확인

광고 관련 정보(광고 ID 등)코인 모으기 화면을 열 때(광고 동의 확인과 광고 준비), 보상형 광고를 볼 때Google AdMob이 광고를 보여 주고 보상을 확인

현재 앱에는 현금 결제(인앱 결제)가 없어요. 게임 코인은 게임 안에서만 얻고 쓰며, 결제 정보는 처리하지 않아요.

광고 SDK(Google Mobile Ads)는 앱에 포함되어 있어요. 광고 SDK가 Google에 보내는 정보와 그 시점은 Google 정책에 따라요.

앱은 연락처, 위치, 사진, 다른 앱의 화면 내용을 수집하지 않아요. 플로팅 친구는 화면 위에 작은 캐릭터 창만 띄우고, 다른 앱의 내용을 읽지 않아요.

2. 처리를 맡기는 곳

  • Supabase(Supabase Pte. Ltd., 서버·로그인): 계정, 백업, 게임 코인 기록 보관과 서버 운영 로그. 서버 위치: 일본 도쿄(AWS ap-northeast-1).
  • Google: Google 로그인(선택), AdMob 광고와 광고 동의 화면(UMP). Google 개인정보처리방침

이 밖의 곳에 개인정보를 팔거나 제공하지 않아요.

3. 개인정보의 국외 이전

3-1. 국외 보관·처리 위탁: Supabase (서버·로그인)

운영자는 앱 서버와 로그인을 Supabase에 맡기고, 개인정보는 국외(일본)에 보관돼요.

이전받는 자Supabase Pte. Ltd. (싱가포르) · 문의: privacy@supabase.com
이전 국가·처리 지역데이터 저장: 일본(AWS 도쿄 리전 ap-northeast-1).
서비스를 운영하는 법인은 싱가포르의 Supabase Pte. Ltd.예요. Supabase가 서비스 운영·지원에 쓰는 하위 처리자와 그 국가는 Supabase가 공개한 하위 처리자 목록을 따라요.
이전 항목1번 표의 계정 번호, 로그인 세션 정보(IP 주소, 접속한 앱 정보), Google 계정 연결 정보(연결한 경우만), 게임 진행 백업, 게임 코인·아이템 기록, 기기 모델명
이전 시기·방법앱을 이용할 때마다 인터넷(HTTPS 암호화 통신)으로 전송
이용 목적서버 운영, 로그인, 게임 데이터 보관(처리 위탁·보관)
보유·이용 기간4번 "보관 기간과 삭제"와 같아요
법적 근거「개인정보 보호법」 제28조의8 제1항 제3호: 정보주체와의 계약(앱 서비스 제공)을 체결·이행하는 데 필요한 국외 처리위탁·보관으로서, 이전 사항을 이 처리방침에 공개해요.
거부 방법과 효과서버 없이는 앱을 쓸 수 없어서, 거부하려면 앱 이용을 멈추고 계정을 삭제해야 해요. 거부하면 앱을 쓸 수 없어요.

3-2. Google이 직접 처리하는 정보: Google 로그인·AdMob 광고

Google 로그인과 AdMob 광고는 Google이 제공하는 서비스예요. 이 과정의 정보는 사용자의 기기에서 Google로 직접 전송되고, Google이 Google 개인정보처리방침에 따라 처리해요. 운영자는 광고 보상 확인용 일회용 번호 외에 Supabase에 보관한 계정·게임 정보를 Google에 넘기지 않아요. Google 로그인을 연결하면 Google이 보내 준 정보(1번 표)는 위 3-1처럼 Supabase에 보관돼요.

처리하는 곳Google LLC (미국) · 문의: Google 한국 거주자를 위한 개인정보 관련 추가 정보에 안내된 연락처
처리 지역국외에 있는 Google 데이터 센터(위 Google 안내 기준. 국가별 목록은 Google이 따로 밝히지 않아요)
항목Google 로그인: 사용자가 Google에 직접 로그인하는 과정의 정보(연결한 경우만)
AdMob(Google 모바일 광고 SDK 안내 기준): IP 주소, 앱 안의 광고 관련 상호작용, 진단 정보, 광고 ID 등 기기 식별자
시기·방법Google 계정을 연결할 때, 코인 모으기 화면을 열거나 광고를 볼 때 인터넷(암호화 통신)으로 전송
목적Google 로그인 처리, 광고 제공과 보상 확인
보유 기간Google 정책에 따라요
거부 방법과 효과Google 로그인: 연결하지 않으면 돼요. 게임은 그대로 쓸 수 있지만 기기 변경 때 진행을 복원할 수 없어요.
AdMob: 코인 모으기 화면을 열지 않으면 광고를 준비하지 않아요. 이 경우 광고 보상을 받을 수 없어요. 맞춤 광고는 광고 동의 화면과 기기의 Google 설정에서 바꿀 수 있어요.

4. 보관 기간과 삭제

  • 계정과 게임 데이터는 사용자가 계정을 삭제할 때까지 보관해요.
  • 계정을 삭제하면 아래 정보가 바로 삭제돼요.
    • 로그인 계정, 로그인 세션, Google 로그인 정보와 계정 연결 정보
    • 친구(펫), 성장, 친밀도, 추억 등 게임 진행 기록
    • 보유 게임 코인과 아이템, 게임 코인 사용·보상 원장
    • 출석, 미니게임, 선물 코드 사용, 광고 보상 기록, 기기 변경 기록, 서버 백업
  • 삭제 후에도 아래 정보는 남을 수 있어요.
    • 최소 삭제 이력: 삭제된 계정의 무작위 계정 번호(UUID), 삭제 시각, 삭제 방법(앱 또는 이메일 요청), 함께 지운 백업 개수. 삭제된 계정이 다시 서비스를 쓰지 못하게 막는 데 써요. 이메일·이름·Google ID는 없지만 계정 번호가 남는 가명 정보예요(완전한 익명 정보가 아니에요). 보관 기간: 삭제 후 7일(하루 한 번 자동 정리, 늦어도 8일 안에 삭제).
    • 선물 코드 사용 집계: 코드별로 삭제된 계정이 사용한 횟수(숫자)만 남고, 어느 계정이 썼는지는 남지 않아요.
    • Supabase 운영 로그: 요청 시각, 요청 경로 등 접속 기록(IP 주소가 포함될 수 있어요). Supabase 요금제의 기본 보관 기간이 지나면 자동으로 지워져요. 현재 요금제(Free) 기준 API·데이터베이스 로그 1일, 로그인 감사 로그 24시간.
    • 이미 만들어진 서버 백업: 운영자가 직접 만든 데이터베이스 백업에는 삭제 전 데이터가 남을 수 있어요. 장애 복구에만 쓰고 최대 14일 보관해요(최신 정상 백업 약 2개 유지). 백업으로 복구할 때는 복구본을 쓰기 전에, 백업 이후 삭제된 것으로 확인되는 계정을 다시 삭제해요. 현재 요금제에는 Supabase 자동 백업이 없어요.
    • 이메일 삭제 요청 기록: 요청 메일과 회신은 처리를 마친 뒤 30일 동안 보관하고 그 뒤 영구 삭제해요.
  • 삭제 방법: 계정 삭제 안내 (앱 안에서 바로 삭제, 또는 이메일 요청)

언제든 자신의 정보 열람, 정정, 삭제, 처리 중지를 요청할 수 있어요. 광고 개인 맞춤 설정은 기기의 Google 설정과 앱의 광고 동의 화면에서 바꿀 수 있어요.

6. 아동

Pocket Life는 만 16세 미만 아동을 대상으로 제작된 앱이 아닙니다.

7. 안전 조치

서버와의 통신은 모두 암호화(HTTPS)돼요. 기기 안의 로그인 정보는 Android 키 저장소로 암호화해 보관해요. 앱에는 서버 관리용 비밀 키가 들어 있지 않아요.

8. 변경

이 방침이 바뀌면 이 페이지와 앱 안내로 알려 드려요.
