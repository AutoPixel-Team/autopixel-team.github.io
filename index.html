HOW IT WORKS

단 3단계로 완성하는 자동화

복잡한 프로그래밍 지식 없이 마우스 조작 몇 번으로 바로 실행합니다.

1

대상 창 선택

자동화를 실행할 프로그램이나 웹 브라우저 창을 마우스로 클릭하여 지정합니다.

2

화면 이미지 캡처

클릭할 버튼이나 아이콘을 마우스로 드래그하여 캡처하고 클릭 동작을 설정합니다.

3

시작 (F5)

단축키 F5를 누르면 마우스 커서 간섭 없이 백그라운드에서 스스로 작업을 수행합니다.

위 시연처럼 [대상 창 클릭 ➔ 버튼 드래그 ➔ 시작]만 누르면 마우스 간섭 없이 백그라운드 자동화가 즉시 작동합니다.

FAQ

자주 묻는 질문

궁금하신 점을 빠르게 확인해 보세요.

Q. 매크로 실행 중에도 제 마우스로 다른 작업을 할 수 있나요? ▼
네, 가능합니다! 기본 조작 모드인 '가상 클릭 (마우스 이용 가능)'을 사용하시면 윈도우 OS의 가상 메시지 방식으로 대상 창에 직접 신호를 전달하므로, 사용자의 물리 마우스 커서에는 일절 간섭하지 않습니다.
Q. 작업 창 위에 다른 창이 덮여 있어도 동작하나요? ▼
네, 작업 창 위에 웹브라우저나 엑셀 등을 띄워 가려두어도 정상 동작합니다. 단, 윈도우 작업표시줄로 '최소화(_)'할 경우 OS가 그래픽 렌더링을 중단하므로 창을 최소화하지 마시고 다른 창 뒤에 덮어두시는 것을 권장합니다.
Q. 프로그램 설치나 별도의 환경 설정이 필요한가요? ▼
아닙니다. AutoPixel Studio는 별도 설치 과정(Setup)이나 파이썬 등의 런타임 설치가 필요 없는 단일 실행 파일(.exe) 포터블 형태로 제공됩니다. 다운로드 후 더블 클릭하시면 즉시 실행됩니다.
Q. 대상 창의 크기나 해상도가 달라져도 인식되나요? ▼
스마트 이미지 매칭 알고리즘과 함께 상단 툴바의 [크기 복원] 기능을 지원합니다. 클릭 한 번으로 매크로 제작 당시의 대상 창 크기와 위치를 1초 만에 그대로 맞춰주므로 항상 안정적인 인식이 가능합니다.
