SECTION 02

상단 제어 바 (프로젝트 관리 및 창 바인딩)

실제 툴 상단 1열과 2열의 각 버튼 영역을 크롭하여 실제 모양과 기능을 1:1로 매칭했습니다.

새 프로젝트 / 열기 / 저장 PROJECT
제작 중인 모든 이미지 템플릿과 타임라인 시퀀스 설정을 단일 JSON 프로젝트 파일로 보관하거나 불러옵니다.
안내: 캡처한 이미지 파일들이 프로젝트 파일과 동일한 상대 경로에 함께 저장되므로, 다른 PC로 통째로 옮겨도 경로 깨짐 없이 즉시 실행됩니다.
대상 창 드롭다운 & 창 선택 TARGETING
[창 선택] 버튼을 누른 뒤 마우스 십자선 커서로 원하는 프로그램을 클릭하면 내부 창 핸들(HWND)이 즉각 자동 바인딩됩니다.
창 확인: [창 확인]을 누르면 바인딩된 실제 창 테두리가 3회 깜빡입니다. 올바른 프로세스가 연결되었는지 눈으로 즉시 검증할 수 있습니다.
시작 (F5) / 단독 테스트 (F6) / 정지 (F7) F5 / F6 / F7
F5로 전체 루프를 가동하고, F6(단독 테스트)으로 현재 타임라인에서 선택된 단 1개의 스텝만 즉시 인식/클릭 동작을 1회 검증합니다.
비상 정지: 매크로가 실행되는 동안 언제든 키보드 F7 키를 누르면 모든 조작과 스레드가 즉시 안전 중단됩니다.
조작 모드 & 반복 설정 VIRTUAL INPUT
Windows PostMessage / SendMessage API를 사용하여 대상 창에 직접 가상 마우스 신호를 전달합니다.
무간섭 환경: 매크로가 백그라운드에서 동작하는 동안 사용자는 실제 마우스로 웹서핑이나 엑셀 문서 작성을 자유롭게 병행할 수 있습니다.
SECTION 03

해상도 동기화 & 최적 크기 복원

창 크기가 변경되면 캡처 픽셀 배율이 달라져 인식률이 저하됩니다. 창 크기를 항상 100% 동일하게 유지해 주는 핵심 바입니다.

가로/세로 px 비율 조절 & [기억] / [복원] RESOLUTION LOCK
- 비율 조절: 가로 픽셀을 입력하면 표준 16:9 비율에 맞추어 세로 픽셀을 자동 계산하여 대상 창 크기를 즉시 일괄 조정합니다.
- 기억: 템플릿 이미지를 최초 캡처할 당시의 완벽한 가로x세로 해상도를 메타데이터에 스냅샷으로 저장합니다.
- 복원: 사용자가 창 크기를 임의로 드래그하여 흐트러뜨려도, [복원] 클릭 한 번으로 기준 크기로 강제 원상 복구합니다.
결과: 모니터 해상도가 다른 타 PC나 노트북으로 프로젝트를 옮겨도 100% 동일한 픽셀 매칭률을 보장합니다.
SECTION 04

템플릿 이미지 관리 패널 (좌측)

인식할 버튼/아이콘 이미지를 등록하고 정밀한 비전 감도 조건을 설정합니다.

캡처 스텝 자동 생성 & 3초 캡처 1-CLICK / DELAY
- 캡처 스텝 자동 생성: 화면을 드래그하면 템플릿 등록과 타임라인 클릭 스텝이 한 번에 자동 생성됩니다.
- 3초 캡처: 마우스를 올렸을 때만 열리는 드롭다운 메뉴나 마우스 오버 툴팁을 캡처할 수 있도록 3초 카운트다운 후 캡처 화면을 띄웁니다.
효과: 마우스 클릭 즉시 사라지는 웹 팝업이나 서브 메뉴를 여유롭게 캡처할 수 있습니다.
인식 임계치(Confidence) & Canny 엣지 OPENCV MATCH
- 임계치 슬라이더 (기본 80%): 일치율 기준을 정밀 조정합니다. 고정 버튼은 85~90%, 반투명이나 음영 변화가 있는 요소는 70~75% 권장.
- 배경색 무시 (Canny 엣지): 색상 정보를 배제하고 외곽 윤곽선(Edge)만 대조하여 다크모드/라이트모드 변화에도 형태를 찾아냅니다.
안정성: 계절별 테마 변화나 시간대별 색상 톤이 바뀌는 환경에서 탁월한 인식률을 자랑합니다.
서칭 영역(ROI: Region of Interest) 제한 & 인식 테스트 ROI SPEEDUP
전체 화면을 스캔하지 않고 [드래그 지정]으로 탐색 범위를 한정합니다. CPU 연산 부하를 80% 이상 줄이며 탐색 속도를 5~10배 빠르게 단축합니다.
설정 후 [인식 테스트] 버튼을 누르면 현재 대상 화면에서 감지된 유사도 점수와 감지 좌표를 실시간으로 테스트합니다.
오탐 방지: 화면의 다른 구역에 유사한 아이콘이 여러 개 존재하더라도 원하는 영역만 검색하므로 오탐지가 100% 원천 차단됩니다.
SECTION 05

3대 워크플로우 뷰 및 시퀀스 편집 (중앙)

카드형 타임라인, 클래식 표 뷰, 플로우차트 도식도 3가지 모드로 작업 흐름을 자유롭게 설계합니다.

3대 워크플로우 뷰 전환 VIEW MODES
- 카드 타임라인: 캡처 이미지 썸네일과 동작 카드를 한눈에 직관적으로 보며 작업.
- 클래식 표 뷰: 수십 개의 스텝을 엑셀 행처럼 컴팩트하게 일괄 확인.
- 알고리즘 플로우차트: 조건 분기(IF 점프) 흐름을 노드 다이어그램으로 시각화.
특징: 작업자의 취향과 자동화 복잡도에 따라 언제든 원클릭으로 화면 뷰를 변경할 수 있습니다.
스텝 편집 및 되돌리기(Undo/Redo) CTRL+Z / CTRL+Y
- 빠른 추가 / + 스텝 추가: 정밀 대기(Sleep), 특정 스텝 점프(GOTO), 루프 처음으로 리셋, 특정 좌표 클릭, 사각 영역 클릭, 화면 드래그(Swipe), Enter/Esc 키 입력 등 자주 쓰는 동작을 원클릭 즉시 삽입.
- 되돌리기 / 다시실행: 실수로 스텝을 삭제하거나 순서를 바꿨을 때 단축키(Ctrl+Z / Ctrl+Y)로 언제든 안전하게 복구.
그룹화: [그룹 보기]를 활용하면 수십 개의 반복 스텝을 폴더처럼 깔끔하게 묶어 관리할 수 있습니다.
SECTION 06

우측 스텝 상세 속성 (Inspector Panel)

선택한 스텝 카드의 정밀 좌표 오프셋과 예외 처리 조건을 실시간 설정합니다.

상세 속성 인스펙터 패널 INSPECTOR
중앙 타임라인에서 스텝 카드를 클릭하면 우측 패널에 해당 스텝의 클릭 오프셋(X, Y), 클릭 후 대기 시간, 실패 시 예외 처리 정책이 즉각 로드됩니다.
실패 시 대응: [매크로 즉시 정지], [다음 스텝 건너뛰기], [3회 재시도] 옵션을 통해 일시적 네트워크 지연에도 멈추지 않는 방탄 매크로를 구성할 수 있습니다.
클릭 오프셋 & 예외 분기 TIP PRO TIP
- 상대 오프셋 (Offset X, Y): 캡처한 이미지 정중앙 대신, 예를 들어 '아이디' 글자가 적힌 라벨 영역을 템플릿 이미지로 캡처해 두고 그 오른쪽 100px 지점의 빈 입력창을 클릭하도록 상대 좌표를 지정할 때 활용합니다.
- 동작 후 대기 시간 (Sleep): 버튼 클릭 후 웹페이지나 프로그램 화면이 렌더링될 수 있도록 0.3초~1.0초의 적절한 완충 대기 시간을 부여하는 것이 좋습니다.
로그 콘솔: 하단 실시간 이벤트 콘솔을 통해 각 스텝별 수행 시간(ms)과 인식 성공 여부를 밀리초 단위로 확인할 수 있습니다.
SECTION 07

멀티 실행 러너 (Multi-Runner) 상세 도감

여러 개의 창을 동시에 띄워 서로 다른 자동화 작업을 병렬로 제어하는 다중 실행 관제 센터입니다.

AutoPixel Studio - 멀티 실행 (Runner)
병렬 실행 센터
[상단] 전체 일괄 시작/정지 & 창 크기 일괄 맞춤 [하단] 다중 작업 인스턴스 카드 목록 [기능] 백그라운드 무간섭 독립 병렬 스레드 구동
러너 상단 마스터 일괄 제어 바 MASTER TOOLBAR
- + 새 작업 추가: 실행 목록에 새로운 작업 카드 행을 추가합니다.
- 전체 선택 / 전체 해제: 목록의 모든 작업 카드를 일괄 선택하거나 체크 해제합니다.
- ▶ 전체 일괄 시작 / ■ 전체 일괄 정지: 바인딩된 모든 창의 매크로를 단 1클릭으로 동시 가동하거나 비상 시 즉각 정지합니다.
- ⧉ 전체 창 크기 일괄 맞춤: 띄워진 다중 클라이언트 창들을 기준 최적 크기(1920x1080 등)로 한 번에 균일하게 리사이징 정렬합니다.
- 💾 세팅 저장 / 📁 세팅 불러오기: 다중 작업 구성과 창 바인딩 매핑 상태를 프리셋 파일로 저장해 매일 출근 시 원클릭으로 세팅을 복원합니다.
생산성: 4~8개의 창을 일일이 켜고 맞출 필요 없이, [세팅 불러오기] -> [전체 창 크기 맞춤] -> [전체 일괄 시작]으로 3초 만에 모든 업무 준비가 완료됩니다.
개별 작업 인스턴스 카드 구성 TASK INSTANCE
- 📁 작업 선택: 해당 인스턴스에 실행할 Studio 프로젝트 파일(.json)을 지정합니다.
- ⧉ 대상 창 선택 (미선택 ▾): 신호를 전송할 대상 윈도우 창 핸들을 매핑합니다.
- 창 확인: 바인딩된 창이 화면에서 깜빡여 대상이 맞는지 즉시 검증합니다.
- ⧉ 크기 맞춤: 해당 창 1개만 기준 픽셀 해상도로 즉각 맞춥니다.
- 반복 스핀박스 & ▶ 시작: 무한 루프 또는 지정 횟수 반복 후 개별 인스턴스만 독립 시작합니다.
- 상태 표시줄: 현재 창의 매크로 수행 단계, 반복 회차, 실시간 성공/대기 상태가 실시간 출력됩니다.
독립성: 1번 창에서 일시적 로딩 지연이 발생하더라도 다른 창들의 실행 스레드는 전혀 영향받지 않고 100% 독립적으로 정상 동작합니다.
SECTION 08

실무 비즈니스 자동화 시나리오 예시

AutoPixel Studio를 활용하여 매일 반복되는 정형 데이터 처리 및 전산 업무를 자동화하는 합법적인 비즈니스 실전 활용 사례입니다.

CASE 01 ERP / 정산

사내 ERP 일괄 정산 다운로드

매일 오전 사내 ERP 시스템에 로그인하여 날짜 범위를 선택하고, 매출 정산 엑셀 파일을 백그라운드로 안전하게 다운로드받는 시퀀스.

CASE 02 DATA ENTRY

엑셀 목록 기반 웹 폼 반복 입력

엑셀 시트에 정리된 수백 건의 배송 송장 번호나 품목 데이터를 사내 포털 등록 폼에 한 줄씩 순차적으로 자동 기입하고 결과를 저장.

CASE 03 MONITORING

장애 팝업 감지 및 자동 복구 재시작

24시간 구동되는 무인 시스템 화면에 오류 알림창이나 네트워크 단절 팝업이 나타날 경우 [확인] 클릭 및 프로세스 자동 재기동 루틴.
