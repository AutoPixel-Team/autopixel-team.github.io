간편한 실무 연계
가상 클릭 실습 TPL-01
기본 체험: 백그라운드 가상 클릭
내 마우스 커서를 빼앗지 않고 백그라운드로 안전하게 10회 연속 자동 클릭을 수행하는 가장 기초적인 무간섭 자동화 팩입니다.
스텝 구성 및 파라미터
스텝 1: 0.5초 대기 (타깃 준비)
스텝 2: 타깃 버튼 이미지 탐색 ➔ 중심 가상 클릭 (오차 ±2px 랜덤 터치)
반복 설정: 10회 체험 후 자동 완료
✓ 권장: 가상 클릭 모드 초보자 추천
직접 클릭 실습 TPL-02
기본 체험: 마우스 직접 클릭
실제 물리 마우스 커서가 타깃 버튼 위치로 직접 이동하여 하드웨어 클릭 신호를 주입하는 표준 조작 모드 실습 팩입니다.
스텝 구성 및 파라미터
스텝 1: 0.5초 대기 (포커스 안정화)
스텝 2: 타깃 버튼 탐색 ➔ 실제 마우스 이동 & 물리 클릭
반복 설정: 10회 체험 후 자동 완료
✓ 권장: 직접 클릭 모드 하드웨어 입력 호환
돌발 팝업 실습 TPL-03
실전 실습: 돌발 확인 팝업 자동 감지 & 닫기
업무 도중 불시에 튀어나오는 공지/경고 [확인] 팝업창을 조건 트리거로 실시간 감지해 닫고, 본 작업(타겟 클릭)을 끊김 없이 지속하는 예외 대응 팩입니다.
스텝 구성 및 파라미터
스텝 1: 본 작업 타겟 버튼 클릭 (지연 0.5초)
스텝 2: [확인] 팝업 발견 시 ➔ 즉시 닫기 클릭 & 본 작업 복귀
특징: 미발생 시 자연 통과, 출현 시 100% 예외 복구
✓ 양방향 모드 호환 실무 필수 예외
2개 버튼 순차 실습 TPL-04
실전 실습: 2개 버튼 순차 반복 클릭 팩
1번 버튼(요청/조회) 클릭 후 시스템 응답 대기, 2번 버튼(승인/확인)을 순차적으로 수행하는 기본 2단계 프로세스 루프입니다.
스텝 구성 및 파라미터
스텝 1: 1번 버튼 (FIRST BUTTON) 클릭 ➔ 0.6초 대기
스텝 2: 2번 버튼 (SECOND BUTTON) 클릭 ➔ 0.6초 대기
안정성: 버튼별 개별 랜덤 지연(±0.2초) 부여
✓ 권장: 가상 클릭 모드 다단계 시퀀스
제스처 스크롤 실습 TPL-05
실전 실습: 제스처 스크롤 & 타깃 자동 탐색 팩
긴 목록이나 웹 피드를 아래로 드래그(스와이프 스크롤)하며 숨겨진 목표 문서([긴급 결재 / TARGET])를 자동 감지해 승인 클릭합니다.
스텝 구성 및 파라미터
스텝 1: 화면 하단 ➔ 상단 제스처 스와이프 드래그 (500ms)
스텝 2: [결재 승인] 발견 시 즉각 승인 클릭
특징: 시야에 나타날 때까지 연속 탐색 수행
✓ 양방향 모드 호환 모바일/웹 탐색
RGB 픽셀 감시 실습 TPL-06
실전 실습: 서버/장비 상태 감시 및 자동 복구
서버 상태등(LED)의 RGB 색상 변화(정상 녹색 ➔ 장애 빨강)를 O(1) 초고속 픽셀 매칭으로 실시간 감시하고, 장애 시 [서비스 재기동]을 자동 클릭해 복구합니다.
스텝 구성 및 파라미터
스텝 1: 상태등 LED 빨간색(#EF4444) RGB 픽셀 실시간 감시
스텝 2: 빨간색 감지 즉시 [서비스 재기동] 자동 클릭
성능: CPU 점유율 0.1% 미만의 초경량 실시간 관제
✓ 권장: 가상 클릭 모드 초경량 O(1) 관제
활선 드래그 실습 (NEW) TPL-07
실전 실습: 사람다운 활선 드래그 & 드로잉 팩
시작 영역(A)에서 종료 영역(B)으로 마우스가 사람다운 부드러운 활선 곡선(완급 조절 및 자연스러운 손떨림)을 그리며 이동하는 고급 드래그 실습 팩입니다. 캔버스 위젯에 회차별 다채로운 브러시 선이 지워지지 않고 차곡차곡 누적됩니다.
스텝 구성 및 핵심 기술
스텝 1: 0.5초 대기 (캔버스 준비)
스텝 2: 2초 부드러운 곡선 드래그 (시작 A ➔ 종료 B 사각 랜덤 영역)
브러시 누적: 인디고 ➔ 하늘 ➔ 에메랄드 ➔ 주황 ➔ 핑크 선 누적
모드 동기화: 상단 콤보박스 선택에 따라 가상/직접 드래그 100% 연동
✓ 가상 클릭 & 직접 클릭 완벽 지원 최신 정식 탑재
✦ SAFE SIMULATION ENVIRONMENT

AutoPixel 실습 샌드박스 (독립 연습용 창)

실제 중요한 업무 창이나 사내 전산 프로그램을 건드리지 않고도 100% 안전하게 동작 원리를 체험할 수 있도록
각 템플릿에 맞춤 설계된 독립 시뮬레이션 윈도우 창(SandboxWindow)이 함께 열립니다.

🛡️ 100% 무간섭 안전 보장

연습용 창은 메인 창과 완전히 분리된 독립된 윈도우 OS 핸들(HWND)로 구동됩니다. 오작동이나 데이터 훼손 염려 없이 안심하고 매크로를 테스트하세요.

⚡ 다양한 실전 시뮬레이션 모드

기본 클릭 카운터, 돌발 팝업 자동 닫힘, 목록 연속 스크롤, 실시간 상태 감시 및 자동 복구, 곡선 드로잉 캔버스까지 템플릿별 맞춤형 연습 환경이 자동으로 제공됩니다.

🎨 실시간 시각 반응 & 궤적 누적

클릭 카운트 증가, 팝업 자동 닫힘, 상태등 색상 변화(초록 ➔ 빨강 ➔ 복구), 캔버스 다색 곡선 브러시 선 누적 등 모든 동작 결과를 화면에서 즉시 눈으로 확인합니다.

[기본 클릭 & 관제 모드] 정상 상태 감시 및 클릭 반응
타깃 버튼을 백그라운드로 자동 클릭하고 정상 상태 램프를 실시간 감시합니다.
[돌발 대응 & 자동 복구 모드] 팝업 감지 및 장애 복구
돌발 안내창이나 상태등 이상(적색 램프) 발생 시 즉시 감지하여 복구 버튼을 작동시킵니다.
[활선 드래그 & 캔버스 모드] 자연스러운 곡선 드래그 누적
시작 A ➔ 종료 B 랜덤 영역 간의 부드러운 곡선 궤적이 캔버스에 차곡차곡 누적됩니다.
