실제 사용자분들의 소중한 피드백을 바탕으로 매주 더 강력하고 안정적인 자동화 환경을 연구하고 배포합니다.

AutoPixel Studio v1.2.9 LATEST RELEASE 2026년 9월 23일 릴리즈
최신 버전 다운로드 (AutoPixel_Studio.exe)
핵심 요약: 완전 초보자도 1초 만에 업무 자동화를 체감할 수 있는 '6대 추천 템플릿 보관함'과 안전한 독립 연습 공간 '실시간 미니 샌드박스'가 신규 탑재되었습니다! 사전 검증 후 [내 작업으로 연계] 버튼 클릭 한 번으로 내 실무 작업 창 자동 전환 및 버튼 원클릭 재캡처를 지원합니다.
6대 추천 템플릿 보관함 & 원클릭 연계
  • 실무 즉시 적용 6개 핵심 프리셋: 웹 데이터 수집/주기적 새로고침, 팝업 닫기/예외 처리, 듀얼 타겟 순차 제어, 목록 연속 스크롤, 서버 헬스체크 및 RGB 복구, 기본 클릭 루프 탑재.
  • 원클릭 3단계 실무 연계: 샌드박스에서 사전 검증 후 [내 작업으로 연계] 버튼 클릭 한 번으로 내 실무 작업 창 자동 전환 및 버튼 원클릭 재캡처 안내를 제공합니다.
독립 미니 샌드박스(연습용 창) 실시간 시뮬레이션
  • 안전한 가상 연습 공간: 실제 업무 창이나 민감한 프로그램을 건드리지 않고도 매크로 동작 원리를 100% 안전하게 시뮬레이션할 수 있습니다.
  • 템플릿별 6가지 전용 모드: 백그라운드 클릭, 팝업 감지, 듀얼 타겟, 자동 스크롤, 서버 장애/복구 등 각 템플릿에 맞춘 독립 창이 실시간으로 제공됩니다.
AutoPixel Studio v1.2.6 PREVIOUS 2026년 9월 20일 릴리즈
이전 빌드 받기 (v1.2.6)
핵심 요약: 듀얼 및 다중 모니터 완벽 지원 패치가 적용되었습니다. 캡처 시 두 화면이 하나로 압축되던 현상이 완전히 해결되었으며, Windows 11 최신 환경에서의 기기 고유 인증 안정성이 대폭 강화되었습니다.
듀얼 & 다중 모니터 캡처 완벽 지원
  • 화면 왜곡 및 압축 현상 원천 해결: 다중 모니터 환경에서 영역 캡처 시 화면이 하나의 모니터로 강제 축소되던 문제를 해결하여, 여러 모니터에 걸친 전체 화면이 왜곡 없이 시원하게 표시됩니다.
  • 모니터별 동적 안내 배너: 마우스 커서가 이동하는 모니터 화면의 상단 중앙에 안내 배너가 자연스럽게 위치하여, 듀얼 모니터 베젤(이음새)에 글자가 잘리는 현상을 방지했습니다.
Windows 11 기기 식별 엔진 고도화
  • 최신 윈도우 OS 완벽 호환: 구형 시스템 도구가 제거된 Windows 11 최신 빌드에서도 윈도우 네이티브 머신 GUID를 통해 100% 안정적이고 독립된 기기 인증 세션을 보장합니다.

이전 빌드 받기 (v1.2.4)
핵심 요약: 누구나 바로 쉽게 시작할 수 있는 초경량 '간편 모드'가 신규 추가되었습니다. 복잡한 설정 없이 화면 캡처만으로 간편하게 매크로를 만들고 실행할 수 있습니다.
초경량 '간편 모드' 신규 추가 (입문자 친화형 UI)
  • 미니멀 윈도우 크기 자동 전환: 메인 상단 탭 1번에 [간편 모드]를 배치하여, 실행 시 460×680 미니멀 크기로 깔끔하고 가볍게 시작할 수 있습니다.
  • 한눈에 들어오는 3단계 직관적 구성: 복잡한 타임라인이나 설정 창을 보지 않고도, 상단의 [+ 캡처 스텝 자동 생성], [+ 빠른 추가 ▼], [+ 스텝 추가] 버튼으로 원하는 동작을 손쉽게 구성할 수 있습니다.
  • 원클릭 스튜디오 확장 전환: 간편 모드 사용 중 고급 조건 분기나 세부 타임라인 편집이 필요할 때는 언제든 상단의 [정밀 모드] 탭을 눌러 전체 스튜디오 작업창으로 전환할 수 있습니다.
